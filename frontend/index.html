About the Project

Understanding the dataset, methodology and technologies behind IRIS AI.

PROJECT OVERVIEW

Iris Flower Classification Using Machine Learning

This project applies supervised machine learning algorithms to classify Iris flowers into three species based on four physical measurements. It uses the built-in Iris dataset provided by Scikit-learn.

Dataset Features

01 Sepal Length (cm)
02 Sepal Width (cm)
03 Petal Length (cm)
04 Petal Width (cm)

Classification Species

01 Iris Setosa
02 Iris Versicolor
03 Iris Virginica

Machine Learning Methodology

01

Data Exploration

Inspect the Iris dataset and understand its features and target classes.

02

Data Preparation

Prepare features and target labels, then split the dataset into training and testing sets.

03

Model Training

Train four supervised classification algorithms using the training data.

04

Model Evaluation

Evaluate performance using accuracy, precision, recall, F1-score and ROC-AUC.

05

Model Deployment

Integrate the selected trained model into a web-based prediction application.
